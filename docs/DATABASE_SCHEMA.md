## User Model

Represents a user account in the system.

**Fields:**

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `id` | String | @id | Unique user identifier (generated by caller) |
| `name` | String | required | User's full name |
| `email` | String | optional | User's email address |
| `image` | String | optional | Profile picture URL |
| `mobile` | String | @unique, optional | 10-digit mobile number (unique per user) |
| `password` | String | optional | Hashed password (salt:key format) |
| `role` | UserRole | @default(CUSTOMER) | User role: CUSTOMER, ADMIN, or SELLER |
| `cart` | Json | @default({}) | Shopping cart data (stored as JSON) |
| `firstName` | String | optional | First name |
| `lastName` | String | optional | Last name |
| `inactive` | Boolean | @default(false) | Account deactivation flag |
| `verifiedEmail` | Boolean | @default(false) | Email verification status |
| `createdAt` | DateTime | @default(now()) | Account creation timestamp |
| `updatedAt` | DateTime | @updatedAt | Last update timestamp |

**Required for Creating a User:**
- `id` - Must be generated by caller (not auto-generated)
- `name` - User's full name

**Relations:**
- Has many `Rating` records (user reviews)
- Has many `Address` records (delivery addresses)
- Has many `Order` records (purchases)

**Example:**
```javascript
const user = await prisma.user.create({
  data: {
    id: "user_john_doe",
    name: "John Doe",
    email: "john@example.com",
    mobile: "9988776655",
    password: "hashed_password_here",
    role: "CUSTOMER",
    cart: {}
  }
});
```

## Product Model

Represents a product in the catalog.

**Fields:**

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `id` | String | @id, @default(cuid()) | Unique product identifier |
| `name` | String | required | Product name |
| `description` | String | required | Product description |
| `mrp` | Float | required | Maximum Retail Price |
| `price` | Float | required | Selling price |
| `images` | String[] | required | Array of image URLs from S3 |
| `category` | String | required | Product category |
| `inStock` | Boolean | @default(true) | Stock availability |
| `createdAt` | DateTime | @default(now()) | Creation timestamp |
| `updatedAt` | DateTime | @updatedAt | Last update timestamp |

**Required for Creating a Product:**
- `name` - Product name
- `description` - Product description
- `mrp` - Maximum Retail Price (must be >= price)
- `price` - Selling price
- `images` - Array of image URLs (at least one)
- `category` - Product category

**Relations:**
- Has many `OrderItem` records (purchases)
- Has many `Rating` records (reviews)

**Example:**
```javascript
const product = await prisma.product.create({
  data: {
    name: "Premium Almonds",
    description: "High-quality California almonds",
    mrp: 520,
    price: 449,
    images: ["https://s3.example.com/almond.jpg"],
    category: "Dry Fruits",
    inStock: true
  }
});
```

## Order & OrderItem Models

Represents purchases and individual items in orders.

### Order Model

**Fields:**

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `id` | String | @id, @default(cuid()) | Unique order identifier |
| `total` | Float | required | Order total amount |
| `status` | OrderStatus | @default(ORDER_PLACED) | Order status |
| `userId` | String | required, @relation | Customer user ID |
| `addressId` | String | required, @relation | Delivery address ID |
| `isPaid` | Boolean | @default(false) | Payment status |
| `paymentMethod` | PaymentMethod | required | COD or STRIPE |
| `isCouponUsed` | Boolean | @default(false) | Coupon applied flag |
| `coupon` | Json | @default({}) | Coupon details (if used) |
| `createdAt` | DateTime | @default(now()) | Order creation time |
| `updatedAt` | DateTime | @updatedAt | Last update time |

**Order Status Enum:**
- `ORDER_PLACED` - Initial state
- `PROCESSING` - Being prepared
- `SHIPPED` - In transit
- `DELIVERED` - Completed

**Payment Method Enum:**
- `COD` - Cash on Delivery
- `STRIPE` - Stripe payment

**Required for Creating an Order:**
- `total` - Order total
- `userId` - Customer user ID
- `addressId` - Delivery address
- `paymentMethod` - COD or STRIPE
- `orderItems` - Array of ordered items (nested create)

**Relations:**
- Belongs to `User` (customer)
- Belongs to `Address` (delivery address)
- Has many `OrderItem` records (ordered products)

### OrderItem Model

**Fields:**

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `orderId` | String | required, @relation | Parent order ID |
| `productId` | String | required, @relation | Product ordered |
| `quantity` | Int | required | Number of units |
| `price` | Float | required | Price per unit at purchase time |

**Composite Primary Key:** `(orderId, productId)`

**Required for Creating an OrderItem:**
- `orderId` - Parent order ID
- `productId` - Product ID
- `quantity` - Quantity ordered
- `price` - Price per unit

**Relations:**
- Belongs to `Order`
- Belongs to `Product`

**Example:**
```javascript
const order = await prisma.order.create({
  data: {
    total: 1078.40,
    userId: "user_1",
    addressId: "addr_1",
    paymentMethod: "COD",
    orderItems: {
      create: [
        { productId: "prod_1", quantity: 1, price: 449 },
        { productId: "prod_2", quantity: 2, price: 149 }
      ]
    }
  },
  include: {
    orderItems: { include: { product: true } },
    user: true,
    address: true
  }
});
```

## Address Model

Represents delivery addresses for users.

**Fields:**

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `id` | String | @id, @default(cuid()) | Unique address identifier |
| `userId` | String | required, @relation | User who owns this address |
| `name` | String | required | Recipient name |
| `mobile` | String | required | Recipient's 10-digit mobile |
| `pincode` | String | required | 6-digit postal code |
| `addressLine1` | String | optional | Street address |
| `addressLine2` | String | optional | Additional address info |
| `landmark` | String | optional | Nearby landmark for identification |
| `city` | String | required | City/town name |
| `state` | String | required | State/province name |
| `createdAt` | DateTime | @default(now()) | Creation timestamp |

**Required for Creating an Address:**
- `userId` - User ID
- `name` - Recipient name
- `mobile` - 10-digit mobile number
- `pincode` - 6-digit postal code
- `addressLine1` - Street address
- `city` - City name
- `state` - State name

**Relations:**
- Belongs to `User` (owner)
- Has many `Order` records (orders shipped to this address)

**Example:**
```javascript
const address = await prisma.address.create({
  data: {
    userId: "user_1",
    name: "John Doe",
    mobile: "9988776655",
    pincode: "400001",
    addressLine1: "Flat 302, Sunrise Apartments",
    addressLine2: "Near Marine Lines Station",
    landmark: "Opposite City Hospital",
    city: "Mumbai",
    state: "Maharashtra"
  }
});
```

## Rating Model

Represents product reviews and ratings.

**Fields:**

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `id` | String | @id, @default(cuid()) | Unique rating identifier |
| `rating` | Int | required | Rating value (1-5) |
| `review` | String | required | Review text |
| `userId` | String | required, @relation | Reviewer user ID |
| `productId` | String | required, @relation | Rated product ID |
| `orderId` | String | required, @relation | Order ID (proof of purchase) |
| `createdAt` | DateTime | @default(now()) | Review creation time |
| `updatedAt` | DateTime | @updatedAt | Last update time |

**Unique Constraint:** `@@unique([userId, productId, orderId])` - User can rate same product only once per order

**Required for Creating a Rating:**
- `rating` - Rating value (1-5)
- `review` - Review text
- `userId` - Reviewer ID
- `productId` - Product ID
- `orderId` - Order ID

**Relations:**
- Belongs to `User` (reviewer)
- Belongs to `Product` (rated product)

**Example:**
```javascript
const rating = await prisma.rating.create({
  data: {
    rating: 5,
    review: "Excellent quality almonds, very fresh!",
    userId: "user_1",
    productId: "prod_1",
    orderId: "order_1"
  },
  include: {
    user: { select: { id: true, name: true, image: true } },
    product: true
  }
});
```

## Coupon Model

Represents promotional codes and discounts.

**Fields:**

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `code` | String | @id | Coupon code (primary key) |
| `description` | String | required | Human-readable description |
| `discount` | Float | required | Discount percentage (0-100) |
| `forNewUser` | Boolean | required | Applicable to new users only |
| `forMember` | Boolean | @default(false) | Applicable to members only |
| `isPublic` | Boolean | required | Public vs internal coupon |
| `expiresAt` | DateTime | required | Expiration date/time |
| `createdAt` | DateTime | @default(now()) | Creation timestamp |

**Required for Creating a Coupon:**
- `code` - Unique coupon code
- `description` - Description
- `discount` - Discount percentage (0-100)
- `expiresAt` - Expiration date

**Example:**
```javascript
const coupon = await prisma.coupon.create({
  data: {
    code: "OFF10",
    description: "10% Off for All Users",
    discount: 10,
    forNewUser: false,
    forMember: false,
    isPublic: true,
    expiresAt: new Date("2026-12-31")
  }
});
```

## OTP Models

Handles One-Time Password for SMS/WhatsApp authentication.

### OtpTemplate Model

**Fields:**

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `id` | String | @id, @default(cuid()) | Template identifier |
| `key` | String | @unique | Template key (e.g., LOGIN_OTP) |
| `body` | String | required | Message template with {{otp}} placeholder |
| `createdAt` | DateTime | @default(now()) | Creation timestamp |
| `updatedAt` | DateTime | @updatedAt | Last update timestamp |

**Example:**
```javascript
const template = await prisma.otpTemplate.create({
  data: {
    key: "LOGIN_OTP",
    body: "Your OTP for Mangal Superfoods is {{otp}}. Valid for 5 minutes."
  }
});
```

### OtpCode Model

**Fields:**

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `id` | String | @id, @default(cuid()) | OTP record ID |
| `mobile` | String | required, @index | 10-digit mobile number |
| `code` | String | required | Generated 4-digit OTP |
| `expiresAt` | DateTime | required | Expiration timestamp |
| `used` | Boolean | @default(false) | Consumption flag |
| `createdAt` | DateTime | @default(now()) | Creation timestamp |

**Index:** Mobile number is indexed for fast lookups during verification

**Example:**
```javascript
const otp = await prisma.otpCode.create({
  data: {
    mobile: "9988776655",
    code: "1234",
    expiresAt: new Date(Date.now() + 5 * 60 * 1000) // 5 minutes
  }
});

// Verify OTP
const otpRecord = await prisma.otpCode.findFirst({
  where: {
    mobile: "9988776655",
    code: "1234",
    used: false,
    expiresAt: { gte: new Date() }
  }
});

if (otpRecord) {
  await prisma.otpCode.update({
    where: { id: otpRecord.id },
    data: { used: true }
  });
}
```

## Relations Overview

```
User
├── Has Many: Rating (user reviews)
├── Has Many: Address (delivery addresses)
└── Has Many: Order (purchases)

Product
├── Has Many: OrderItem (purchases)
└── Has Many: Rating (reviews)

Order
├── Has One: User (customer)
├── Has One: Address (delivery location)
└── Has Many: OrderItem (items in order)

OrderItem
├── Belongs To: Order (parent)
└── Belongs To: Product (ordered product)

Address
├── Belongs To: User (owner)
└── Has Many: Order (orders shipped here)

Rating
├── Belongs To: User (reviewer)
└── Belongs To: Product (rated product)

Coupon
└── No direct relations (referenced in Order.coupon JSON)

OtpTemplate
└── Referenced by OtpCode (template for message)

OtpCode
└── No direct relations (one-time use)
```

## Queries Reference

### Get User with All Relations
```javascript
const user = await prisma.user.findUnique({
  where: { id: "user_1" },
  include: {
    ratings: true,
    Address: true,
    buyerOrders: true
  }
});
```

### Get Product with Ratings
```javascript
const product = await prisma.product.findUnique({
  where: { id: "prod_1" },
  include: {
    rating: true,
    orderItems: {
      include: { order: true }
    }
  }
});
```

### Get Order with All Details
```javascript
const order = await prisma.order.findUnique({
  where: { id: "order_1" },
  include: {
    user: true,
    address: true,
    orderItems: {
      include: { product: true }
    }
  }
});
```

### Get User's Orders
```javascript
const userOrders = await prisma.order.findMany({
  where: { userId: "user_1" },
  include: {
    orderItems: { include: { product: true } },
    address: true
  }
});
```

### Get Product Ratings with User Info
```javascript
const ratings = await prisma.rating.findMany({
  where: { productId: "prod_1" },
  include: {
    user: { select: { name: true, image: true } }
  }
});
```
